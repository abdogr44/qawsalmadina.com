# شركة قوس المدينة لتصنيع وتشكيل الزجاج والمرايا
# Qaws Al-Madina Company for Glass & Mirror Manufacturing

الموقع الرسمي فائق البساطة (Ultra-Minimal) لشركة **قوس المدينة لتصنيع وتشكيل الزجاج والمرايا** في طرابلس، ليبيا.
The official minimalist web page for **Qaws Al-Madina Glass & Mirror Manufacturing Co.** in Tripoli, Libya.

---

## 🌟 المحتوى والميزات (Features)

- **فائق البساطة والأناقة (Ultra-Minimalist Single-Fold Design)**: يركز مباشرة وبدون حشو على اسم الشركة، النشاط والخدمات، ووسائل التواصل المباشرة.
- **هندسة i18n و RTL دقيقة (Flawless RTL & Bidi Layout)**:
  - استخدام خصائص CSS المنطقية (`text-start`, `ps-*`, `pe-*`, `ms-*`, `me-*`).
  - عزل الأرقام والاتجاهات عبر `<bdi dir="ltr">` لمنع قلب الأرقام أو تشويه الرموز في العربية.
  - دعم ثنائي فوري (عربي / إنجليزي) بدون إعادة تحميل.
