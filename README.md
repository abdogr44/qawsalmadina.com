# شركة قوس المدينة لتصنيع وتشكيل الزجاج والمرايا
# Qaws Al-Madina Company for Glass & Mirror Manufacturing

الموقع الرسمي لشركة **قوس المدينة لتصنيع وتشكيل الزجاج والمرايا** في طرابلس، ليبيا.
The official web platform for **Qaws Al-Madina Glass & Mirror Manufacturing Co.** in Tripoli, Libya.

---

## 🌟 الميزات والمواصفات (Features)

- **ثنائي اللغة بالكامل (Full Bilingual AR / EN)**: محول لغات فوري (Language Switcher) مع دعم كامل للاتجاهين RTL و LTR، وحفظ التفضيل محلياً (`localStorage`).
- **تصميم عصري راقٍ (Luxury Glassmorphism UI)**: واجهة مستخدم مبنية بأحدث تقنيات Tailwind CSS مع مؤثرات زجاجية ولمعان المرايا وألوان الكريستال والأزرق الياقوتي.
- **تجاوب كامل (100% Responsive)**: أداء فائق وسرعة تحميل وتوافق تام مع كافة الهواتف والأجهزة اللوحية والشاشات العريضة.
- **أقسام متكاملة**:
  - نبذة عن الشركة والمصنع والتكنولوجيا (فرن التقسية الحرارية، ماكينات CNC الإيطالية، خطوط الجلي والشطف).
  - المنتجات والخدمات (الزجاج السيكوريت المقسى، الزجاج المزدوج DGU، الزجاج المصفح، مرايا LED الذكية، كبائن الشاور، والدرابزين).
  - دليل سماكات الزجاج التفاعلي (Interactive Glass Specs Guide: 6mm, 8mm, 10mm, 12mm, 19mm).
  - معرض أعمال ومشاريع واقعية مع إمكانية التصفية (Filterable Project Portfolio).
  - نموذج طلب عرض سعر تفاعلي يرسل التفاصيل مباشرة عبر الواتساب أو البريد.
  - الأسئلة الشائعة وتفاصيل الاتصال السريع المباشر في طرابلس.

## 🚀 المعاينة والتشغيل المحلي (Local Preview & Serving)

لتشغيل الموقع محلياً على جهازك:

```bash
# باستخدام بايثون:
python -m http.server 8000

# أو باستخدام سكريبت PowerShell المرفق:
powershell -ExecutionPolicy Bypass -File serve.ps1
```

افتح المتصفح على: `http://localhost:8000`
